# IPL Player Images

This directory contains placeholder images for IPL players. For a production deployment, replace these with actual player headshots.

## Image Requirements
- **Format**: JPG or PNG
- **Size**: 200x200px minimum
- **Style**: Professional headshot, team jersey or action pose
- **Background**: Solid color or transparent
- **Naming**: `{player-id}.jpg` (lowercase, no spaces)

## Current Players
All 500 players in the database reference images in this folder using the pattern: `{player-id}.jpg`

## Adding Real Images
1. Take professional player headshots
2. Resize to 200x200px minimum
3. Save as `{player-id}.jpg`
4. Replace placeholder files

## Note
The current system uses placeholder images. For production use, add real player photos for authentic IPL experience.
