# 1.2 — IPL Auction Game

This repository contains the `ipl-auction-game` project (frontend and backend).

Repository layout:

- ipl-auction-game/
  - backend/
  - frontend/

Notes:
- An embedded Git repository exists at `ipl-auction-game` in some working trees. If you intend for that folder to be a separate repository, use a submodule instead (see git submodule). If you want the contents included in this repository, remove the nested `.git` directory from `ipl-auction-game` and commit.

CI: A GitHub Actions workflow is provided at `.github/workflows/node-ci.yml` to install and build the backend/frontend when present.
